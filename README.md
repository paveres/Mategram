## Что есть в Mategram

**Дизайн**
- Профиль: размытый фон из аватарки на весь экран, все блоки в жидком стекле, квадратная аватарка
- Круглые стеклянные кнопки в профиле
- Карточка музыки в профиле с обложкой
- Меню сообщения: Выбрать, Скопировать и Удалить одной строкой, без размытия экрана
- «+» вместо скрепки: короткое меню, которое тянется вверх до полного
- Liquid Glass: стекло на сообщениях и на кнопках ботов

**Режим призрака**
- Без прочтения, «печатает», онлайна, просмотра историй и прослушивания
- Настройка по видам действий, только в личных чатах, исключения по чатам
- «Прочитать на сервере», ответ с прочтением, задержка отправки, всегда в сети

**Профиль**
- ID, датацентр, дата регистрации и создания
- Скрытие эмодзи-статуса, цвета профиля, подарков и рейтинга

**Чаты**
- Перевод через Google и «Перевести» всегда
- Фильтр слов, фильтр залго, скрытие реакций и заблокированных
- Двойной тап для правки, счётчик символов, отправка по Return
- Время у служебных сообщений, секунды, точные просмотры и визиты

**Список чатов и вкладки**
- Скрытие историй, заголовка, «Все чаты», вкладки «Звонки», подписей вкладок
- Память последней папки, превью в одну строку, без свайпов

**Медиа и звонки**
- Всегда HD, ускорение скачивания, задняя камера для кружков
- Внешний видеоплеер, системное окно «Поделиться»
- Подтверждение звонка, звонки через TCP, встроенный микрофон

**Настройки**
- Скрытие любого пункта настроек
- Перенос настроек через буфер обмена
