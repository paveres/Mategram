# Mategram: итоговый список функций

> Обновление: по решению владельца убраны #40 (кнопка поиска у таб-бара) и #91 (поиск по настройкам), итого 136 функций. Этапы и логика каждой функции: `docs/PLAN.md`.

Состав: **все функции Nextgram** (N) + **режим призрака из Ghostgram** (G) + **функции Swiftgram, которых нет в Nextgram** (S). Всё пишется заново, без копирования кода.
Сложность: **Л** лёгкая (флаг и хук, до дня), **С** средняя (несколько дней), **Т** тяжёлая (неделя и больше, нужны специальные знания).
Убрано из Nextgram: чужая подписка (`HeyPainSubscribe`), внедрённые dylib (`KeychainFix`, `Sideloadbypass`), собака «разработчика», брендинг Nextgram. Pro и оплата Swiftgram не берутся, всё бесплатно.

## 8. Пересечения, которые убираем

- **Невидимые истории Swiftgram** заменяются «невидимыми историями» режима призрака (#105): один механизм вместо двух.
- **Перевод, расшифровка, камера, качество фото, ускорение**: в Nextgram уже есть, из Swiftgram берём только движки и перевод чата (#127–128).
- **Бэкап настроек в Keychain**: в Nextgram он для настроек (#88), из Swiftgram добавляем бэкап **сессий** (#117).
- **Иконки приложения, снег, новогодние эффекты**: делаем свои, не копируем чужие.

## 10. Что может блокировать

- **Подпись и Sideloadly.** Приложение ставится без App Store: часть функций (Live Activity, App Group для расширений) зависит от профиля подписи (на бесплатном Apple ID уже ловили чёрный экран из-за App Group).
- **Лицензия.** Telegram-iOS распространяется под GPL-2.0: исходники своего клиента придётся открыть, если вы его распространяете.
- **Ключи Telegram.** Нужны свои `api_id` и `api_hash`, иначе клиент работать не будет.
- **Правила Telegram.** Режим призрака, пересылка из защищённых чатов и подмены могут нарушать условия Telegram для неофициальных клиентов, учитывать при публикации.
